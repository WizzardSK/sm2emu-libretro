## Scope And Contract

The original Master program is undumped. The reconstructed Master uses Relay
operator inputs, which conflict with rider-friendly selection and confirmation.
The user requests an experimental alternative in the port. This is an explicit
adaptation, not a claim about factory Master switch labels or behavior.

`sm2_power_sled_relay_commands` is visible in System for the three Power Sled
sets only (explicit user exception), after Standalone
Mode and before NVRAM Settings. It defaults to Enabled. Enabled applies only
to `powsledm`, in linked or Standalone play; other programs are no-ops. A content
reload is required. Standalone and Relay Audio remain independent. Linked play
still needs the existing valid Master/Slave roster; this option does not create
missing peers or enable Solo play by itself.

| Intro / attract (4) | Coin P1/P2 or Start P1 | Command 2 opens mode selection |

outside Test. The dedicated Test input remains available. Call cannot confirm

reopen selection; emergency has priority if operator inputs occur together.

## Native Evidence And Implementation

`src/libretro/power_sled_commands.*` patches only the loaded Master program.
No ROM archive, upstream machine implementation, native NVRAM format or
frontend persistence file is rewritten.

The existing database Test-ownership guard at `0x1f0400` remains in front of
the decoder. Its continuation at `0x1f0414` branches to the experimental native
helper in verified empty space `0x1f0b00`. Input edges come from `0x529368`:
Coin bits 0/1, Entry bits 8/10, Call bits 9/11 and operator Start bit 12.
Commands use the original outgoing field `0x5293f4` and the original receivers;
the communication protocol and phase cleanup are retained.

Selection confirmation at `0x33564` and the four static departure callbacks
use Entry-only mask `0x0500`. This avoids Call triggering local confirmation
and departure while simultaneously requesting Emergency Stop.

The native departure sound task `0x330d0` emits command 10 at its intermediate
counter and command 11 when its native counter passes 400, then clears its
scheduler callback at `0x33118`. All four model paths finish their forward
animation at frame 380 and repeat the final pose afterwards. The guarded
completion detour at `0x33118` first clears the original task, then emits
command 4 only while still in phase 5. A pending Emergency Stop is preserved.
There is no frontend countdown, wall-clock delay or scheduler RAM scan in the
production implementation. Native animation/audio speed is unchanged.

Emergency Stop command `0x100` was already identified and qualified against
all three programs in `POWER_SLED_OPERATOR_AND_LAYOUT_ANALYSIS_2026-10-10.md`.
Receiver `0xbd760` selects phase 14 and native tasks draw the Emergency Stop
screen. The Slave skips the Relay/Master operator decoder. Its local selection
accepts mask `0x0f00`, while its arm tasks accept Entry `0x0500`; that local
Call acceptance is not evidence that Call already invokes Emergency Stop on
Slave. This integration changes only the Master program.

Expected instructions/operands, the departure callback and empty helper space
are checked before any mutation. A failed guard retains original behavior and
logs the refusal. Helpers do not overlap the Master color, Relay Audio or
Standalone helpers. Save State flag bit 9 records the active reconstruction;
a mismatched selector state is rejected before machine mutation.
